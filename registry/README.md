# registry/

Machine-readable source of truth for the collection. These files are generated
and consumed by the [`tools/`](../tools) scripts; **status and structure are
authoritative here**, and filenames only mirror them.

| File | What it is |
| --- | --- |
| `combinations.json` | One entry per preset — `status` (working/broken), taxonomy, free-block count, per-role block flags, notes. **The authority for working/broken.** |
| `presets.csv` | The same presets flattened to one filterable table (GitHub renders it with search + sort). Generated from `combinations.json` by `tools/gen_matrix.py`. |
| `blocks.json` | Every distinct `@model` id we've captured, with a heuristic category. Generated by `tools/harvest_blocks.py`. |
| `reference-models.json` | The authoritative Pod Go model list by category (transcribed from Line 6 sources). |

Full explanation, schema conventions, and how ids get harvested:
[`docs/presets/naming-and-registry.md`](../docs/presets/naming-and-registry.md) and
[`docs/reference/README.md`](../docs/reference/README.md). Don't hand-edit generated files —
re-run their tool.
