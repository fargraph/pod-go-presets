## Name ↔ internal-id divergences
Reference labels whose actual @model id (or on-device display name) differs from the label. Maintained in `registry/reference-models.json`.

- **Acoustic Sim** → `L6SPB_AcousGtrSimStereo` — id: AcousGtrSim; no HD2_ prefix
- **Auto-Volume Echo** → `HD2_DL4AutoVolStereo` — id: AutoVol, drops 'Echo'
- **Cali Q Graphic** → `HD2_CaliQStereo` — id: CaliQ (no 'Graphic')
- **Digital** → `HD2_DL4DigDelay` — id abbreviates to DigDelay
- **Frequency Shift** → `HD2_MM4FrequencyShifter` — id: FrequencyShifter
- **Lo Res** → `HD2_DL4LowResDelay` — id spells LowRes
- **Multi-Head** → `HD2_DL4MultiheadStereo` — id: Multihead (one token)
- **Seismik Synth** → `HD2_SeismicSynth` — id spells Seismic, not Seismik
- **Stereo** → `HD2_DL4StereoDelay` — legacy delay; name is a bare generic word
